# Contributing

## Setup
```bash
pip install -r requirements.txt
python src/main.py
```

## Modules
- `hasher.py` — SHA-256
- `notarization.py` — record + verify logic
- `database.py` — SQLite ledger
- `main.py` — CLI demo

## Future extensions
- Smart contract storage of hashes
- Django web UI from report screens
- Real eID/PKI integration (sandbox)
